# Editor Vezetiv

Protótipo frontend de um editor educacional para praticar competências de edição de documentos. A proposta é que a IA possa orientar o estudante, enquanto a execução das operações acontece no editor.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Verificação

```bash
npm run lint
npm run build
```

O primeiro MVP inclui uma atividade de formatação básica, autosave em `localStorage`, bloqueio configurável de colagem e verificação semântica do documento via Tiptap/ProseMirror.
